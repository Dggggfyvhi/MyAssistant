# 我的助手 (MyAssistant)

Android 原生 AI 聊天助手 + Agent。

## 本版改动（相对原版）
- **移除语音**：听写 / 语音模式全部去掉
- **移除无线调试（ADB）**：设置与代码都已清理
- **图标**：换成更干净的发光球体矢量图标
- **界面**：保持原版浅色/系统主题风格，输入框贴底原生样式，不魔改深色 HTML 风
- **Agent**：仅保留无障碍服务

## 打包 APK
1. GitHub 新建仓库，上传本目录所有文件（含 `.github`）
2. Actions → “Build APK” → Artifacts 下载 APK

## 使用
1. 设置里填 API 地址、Key，获取模型列表并测试连接
2. 需要操控手机时：设置 → 无障碍 → 开启「我的助手」
3. 回到聊天直接输入即可
