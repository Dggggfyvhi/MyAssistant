# 我的助手 (MyAssistant) v3

Android 原生 AI 聊天助手 + Agent。深色液态玻璃界面，Gemini 风格欢迎页。

## 本版改动
- **全新图标**：发光球体矢量图标，深色渐变背景。
- **欢迎页**：进入后边缘柔光 + 大号 Logo + 随机问候语（「今天想做什么？」等），配置 API 后即可聊天。
- **彻底移除**：
  - 语音识别 / 语音模式
  - 无线调试（ADB）全部相关代码与设置项
- **Agent**：仅保留无障碍服务通道（更稳定）。开启后即可读屏、点击、滚动、打开应用/网页等。
- **界面**：深色液态玻璃 + ChatGPT 式布局，思考中小卡片，可折叠思考过程。

## 打包 APK
1. GitHub 新建仓库，上传本目录全部文件（含 `.github`）。
2. Actions → “Build APK” → Artifacts 下载 `MyAssistant-apk`。

## 使用
1. 打开 App → 右上角或侧边栏进入 **设置**。
2. 填写 API 地址、Key，点「获取模型列表」选模型，再「测试连接」。
3. 如需手机操控：设置里点「去开启」无障碍服务，在系统设置中打开「我的助手」。
4. 回到聊天页直接输入即可。

## 推荐
任意 OpenAI 兼容接口。需要桌面端强 Agent + 真无头浏览器时，可另用 DeepSeek Harness (DSH) 或 Playwright。
