# 我的助手

原生 Android（Kotlin + Jetpack Compose）AI 助手：玻璃质感界面、OpenAI 兼容接口、模型听写/系统语音、Agent（无障碍 或 应用内无线调试）。

## 打包 APK
1. 在 GitHub 新建仓库，上传本目录所有文件（包含隐藏的 `.github`）。
2. Actions → “Build APK” 跑完后，在 Artifacts 下载 `MyAssistant-apk`。

## 使用
1. 侧边栏 → 设置：填 API 地址和 Key，点“获取模型列表”自动填入模型，再“测试连接”。
2. Agent 二选一（都开优先用无障碍）：
   - 无障碍：设置里点“开启”，在系统里打开“我的助手”。
   - 无线调试：开发者选项里打开无线调试 → 使用配对码配对设备 → 分屏打开本应用，端口自动出现，输入配对码点“配对”，再点“连接”。
3. 语音：输入栏麦克风是听写；蓝色按钮进入语音模式。默认用当前模型听写（需模型支持音频输入），不行就在设置里切到“系统”。
