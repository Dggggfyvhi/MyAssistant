# 我的助手

原生 Android（Kotlin + Jetpack Compose）AI 助手：GPT 风格圆角界面、OpenAI 兼容接口、系统语音、无障碍 Agent。

## 打包 APK（不用装任何开发环境）
1. 在 GitHub 新建仓库，把本目录所有文件上传（要包含隐藏文件夹 `.github`）。
2. 打开仓库的 Actions 页面，等 “Build APK” 跑完（首次约 5–8 分钟）；也可手动 Run workflow。
3. 在该次运行页面底部 Artifacts 下载 `MyAssistant-apk`，解压得到 apk，装到手机。

## 第一次使用
1. 侧边栏 → 设置，填 API 地址（形如 `https://xxx/v1`）和 Key，点“获取模型列表”会自动填入模型，再点“测试连接”。
2. Agent：设置里点“开启无障碍”，在系统里找到“我的助手”并开启。Android 13+ 若是灰色，先到 系统设置 → 应用 → 我的助手 → 右上角菜单 → 允许受限制的设置。
3. 对它说“打开学信网，帮我看一下……”。执行时屏幕顶部会出现“点按停止”。

## 语音
- 全部使用手机系统自带的语音识别和朗读。
- 想要更真实的女声：安装 sherpa-onnx 的 Android TTS 引擎 APK，在系统“文字转语音”里设为首选引擎。

## 结构
- `Api.kt` 流式对话、工具调用、模型列表、连接测试
- `Agent.kt` 工具定义 + 无障碍服务（读屏、点击、输入、滚动、按键、打开应用/网址）
- `VM.kt` 对话与 Agent 循环（最多 30 步）
- `Voice.kt` 系统识别/朗读 + 语音模式状态机
- `Ui.kt` 界面
